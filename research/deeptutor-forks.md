# بررسی همهٔ فورک‌های DeepTutor (HKUDS/DeepTutor)

تاریخ بررسی: ۲۵ سپتامبر ۲۰۲۶ — مخزن اصلی: ۴۰٬۲۷۷ ستاره، ~۵٬۱۰۰ فورک، آخرین به‌روزرسانی ۲۴ سپتامبر ۲۰۲۶.

## روش
1. فهرست کامل فورک‌ها از GitHub API گرفته شد (۵٬۱۱۰ فورک مستقیم).
2. فورک‌هایی که بعد از ساخته شدن هیچ push‌ی نداشتند (کپی دست‌نخورده) کنار گذاشته شدند → ۷۹۴ فورک باقی ماند.
3. شاخهٔ پیش‌فرض هر فورک با `main` مخزن اصلی مقایسه شد → **۲۴۴ فورک** حداقل یک commit جلوتر بودند.
4. از این ۲۴۴ تا، حدود ۳۰ مورد فقط commit خودکار «update roster images» داشتند (بدون تغییر واقعی) و بسیاری فقط Dockerfile/CI/README عوض کرده بودند.
5. تغییرات ~۱۴۸ فورکی که ۳ فایل یا بیشتر تغییر داده بودند دستی بررسی شد.

جدول کامل: [`deeptutor-forks-ahead.csv`](deeptutor-forks-ahead.csv)

محدودیت: فقط شاخهٔ پیش‌فرض مقایسه شد؛ جزئیات ۲۰ فورک (diff خیلی بزرگ) دریافت نشد؛ فورکِ فورک‌ها بررسی نشدند.

## نتیجهٔ کلی
- **هیچ فورکی محبوبیت یا بازخورد کاربر واقعی ندارد.** پرستاره‌ترین فورک (`0xSojalSec/AI-Tutor`، ۲۷ ستاره) یک کپی دست‌نخورده است. فورک‌های دارای تغییر حداکثر ۰–۲ ستاره دارند و هیچ issue/نظری از کاربرانی که با آن‌ها چیزی یاد گرفته باشند پیدا نشد.
- اکثر فورک‌ها **صدها تا بیش از ۱۰۰۰ commit عقب‌تر** از نسخهٔ اصلی‌اند، یعنی رفع باگ‌ها و قابلیت‌های جدید رسمی را ندارند.
- مخزن اصلی تقریباً هر روز به‌روز می‌شود؛ بنابراین **بهترین انتخاب همچنان خود DeepTutor اصلی است.**
