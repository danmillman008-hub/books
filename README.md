# books — مطالعهٔ کنکور با DeepTutor (خط فرمان)

این مخزن شامل این‌هاست:

| مسیر | توضیح |
|---|---|
| `*.pdf` | کتاب‌ها و جزوه‌ها |
| `DeepTutor/` | کد DeepTutor اصلی (HKUDS، نسخهٔ 1.6.11، کامیت `a053fec`) **بدون رابط وب**، به‌علاوهٔ ماژول آزمون منتقل‌شده از فورک `anideebee7` |
| `study/exam.db` | بانک سؤال، سابقهٔ پاسخ‌ها، برنامهٔ مطالعه (SQLite، داخل git ذخیره می‌شود) |
| `dt` | اجرای CLI با پایگاه‌دادهٔ `study/exam.db` |
| `setup.sh` | نصب دوباره (محیط مجازی پایتون بعد از ری‌استارت سندباکس پاک می‌شود) |
| `research/` | بررسی فورک‌های DeepTutor |

## چه چیزی از فورک anideebee7 منتقل شد
فورک اصلی ۱۷۳۶ کامیت از نسخهٔ اصلی عقب بود و به PostgreSQL + pgvector نیاز داشت. این قابلیت‌ها روی نسخهٔ فعلی DeepTutor بازنویسی شدند و حالا با SQLite کار می‌کنند:

- **بستهٔ آزمون‌ها** (۳۹ آزمون فورک + **کنکور تجربی** و **کنکور ریاضی**، با تعداد سؤال و زمان رسمی ۱۴۰۵)
- **آزمون تمرینی**، تصحیح با **نمرهٔ منفی یک‌سوم** و محاسبهٔ درصد کنکوری
- **آزمون تشخیصی تطبیقی**: با هر پاسخ درست سختی بالا می‌رود و با پاسخ غلط پایین می‌آید
- **برنامهٔ مطالعهٔ شخصی** بر اساس درس‌ها و مبحث‌های ضعیف
- **پیش‌بینی درصد و رتبه** (تخمینی و تقریبی است، نه مدل رسمی تراز)
- **ساخت یا استخراج سؤال از PDF** با مدل زبانی (`exam generate`)
- کنار گذاشته شد: لایهٔ چندمستأجری، PostgreSQL، referral و رابط وب

## دستورها
```bash
./dt exam packs --country IR                        # بسته‌ها
./dt exam import questions.json --subject زیست‌شناسی  # واردکردن سؤال
./dt exam test new --subject زیست‌شناسی -n 10          # آزمونک
./dt exam test submit 1 "1:2,2:4,3:-"                 # یا "24-13..."  (- = نزدم)
./dt exam diag start                                  # آزمون تشخیصی
./dt exam diag answer 1 3
./dt exam plan new --days 7                           # برنامهٔ مطالعه
./dt exam plan done 5                                 # تیک‌زدن کار
./dt exam predict                                     # پیش‌بینی درصد
./dt exam stats                                       # نقاط ضعف
./dt exam generate کتاب.pdf --from 10 --to 20 --subject زیست‌شناسی   # نیازمند کلید LLM
./dt exam generate دفترچه.pdf --mode extract                          # استخراج تست‌های موجود
```
گزینه‌ها را می‌توان با الف/ب/ج/د، ۱ تا ۴ یا A تا D وارد کرد.

## قابلیت‌های هوش مصنوعی DeepTutor
چت، پایگاه دانش یا RAG روی کتاب‌ها، `deep_solve`، `mastery_path` و `exam generate` به **کلید API یک مدل زبانی** نیاز دارند. تنظیمات در `DeepTutor/data/user/settings/` ذخیره می‌شود. این پوشه در `.gitignore` است و **هرگز push نمی‌شود**.

## Mastery Path (مسیر تسلط) بدون کلید API
`./mp` ابزارهای واقعی موتور Mastery Path دیپ‌تیوتر را مستقیم صدا می‌زند (نقش مدل را ایجنت بازی می‌کند).
داده‌ها در `study/mastery/` ذخیره می‌شود. مسیر فعلی: `zist` (۲۴ ماژول، ۹۴ نقطهٔ دانشی، آستانهٔ تسلط ۹۰٪).
```
./mp tools                                  # فهرست ابزارها
MP_MODE=study ./mp mastery_status '{}'      # هدف بعدی + درصد تسلط
MP_MODE=study ./mp mastery_grade '{"answer":"B"}'
```

## پایگاه دانش LightRAG (کتاب‌ها ← موتور)

- پایگاه دانش `zist` با خط لولهٔ واقعی **LightRAG** ساخته شده است. منابع آن جزوهٔ نکته و تست زیست سنجش (۳۳ تکه) و دفترچهٔ زیست کنکور ۱۴۰۵ (۱۰ تکه) است. گراف حاصل ۵۳۶ گره و ۴۶۹ یال دارد.
- استخراج موجودیت‌ها و روابط را «مدل» انجام داده است: دستیار از طریق `llm_bridge/` که یک API سازگار با OpenAI است. همهٔ پاسخ‌ها در `study/llm_bridge/answers/` ذخیره شده‌اند.
- Embedding از نوع n-gram محلی فارسی (۱۰۲۴ بعدی) است، چون دسترسی به huggingface از این محیط مسدود است.
- راه‌اندازی: `./setup.sh` (یک بار) و سپس `./start.sh`.
- پرسش از پایگاه دانش: `./kbq "سؤال"`. خروجی در `study/logs/kbq_last.json` ذخیره می‌شود.
- این پایگاه دانش به‌عنوان منبع به مسیر تسلط `zist` وصل شده است (`mp_link_kb.py`).
