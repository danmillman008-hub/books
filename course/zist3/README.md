## روش پیشنهادی مطالعه
1. درسنامهٔ یک فصل را بخوان. روی ⚠️ ها مکث کن.
2. تست‌های آخر فصل را **بدون نگاه به پاسخ‌نامه** بزن، بعد پاسخ تشریحی را بخوان.
3. چک‌لیست ✅ را تیک بزن. هر موردی را که نمی‌توانی توضیح بدهی دوباره بخوان.
4. با موتور تمرین کن:
   - آزمون از بانک: `./dt exam test new --subject زیست‌شناسی -n 20` (۶۵ تست این دوره در بانک وارد شده‌اند)
   - مسیر تسلط فصل‌به‌فصل: مسیر `zist3` (۸ ماژول، ۲۵ هدف)، مثلاً:
     `MP_PATH=zist3 MP_MODE=study ./mp mastery_status '{}'`

## ساختار و بازسازی
- `notes/chN.md`: درسنامه (منبع اصلی ویرایش)
- `questions/chN.py`: تست‌ها به صورت `(مبحث، سختی، متن، [۴ گزینه]، پاسخ، توضیح)`
- `python3 course/zist3/build.py`: فایل‌های `chN.md`، فایل کامل دوره و بانک `study/banks/zist3_course.json` را می‌سازد.
  - ورود به بانک: `./dt exam import study/banks/zist3_course.json --subject زیست‌شناسی`
- `mastery_path.py`: تعریف مسیر تسلط `zist3`. پس از ساخت مسیر، `mp_link_kb.py zist3` پایگاه دانش را به آن وصل می‌کند.
- منبع متن: `sources/zist3_textbook.md` (کتاب درسی پاک‌سازی‌شده)
